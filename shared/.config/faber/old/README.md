# old — retired faber projects

Kept for reference, not maintained: `faber-stack` serves `spexmachina` only. Their
relative paths (`../base/…`, sibling projects) predate the move here and no longer
resolve, and they use the retired `faber-stack --instance` flags.

- `faber-stack-service`, `faber-stack-service-li` and `faber-e2e` — the manual end-to-end
  playground; `plans/faber-stack-ci-acceptance.md` is where it comes back from.
- `spexmachina-li` — spexmachina with a local-model implementer.
- `goose-local` — the faber side of the goose scratch container in `docker/goose-local/`.
